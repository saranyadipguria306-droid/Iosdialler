# My Dialer Premium

A phone-first Android dialer with an iOS-inspired visual style.

## Included
- Premium dial pad
- Real phone calls
- Phone contacts + search
- Contact detail screen
- Favorites
- Recent calls from Android call log
- iOS-inspired bottom navigation
- Custom phone app icon
- GitHub Actions APK build

## Build
Push to GitHub, open Actions, choose **Build APK**, then download the
`MyDialer-Premium-debug` artifact.
